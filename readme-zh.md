# MindfulDo - Obsidian 插件

*MindfulDo • 正念之行*

一款平静、美观、功能丰富的 Obsidian 待办清单插件，助你保持条理、降低压力。

![插件预览](https://img.shields.io/badge/Obsidian-Plugin-purple) ![许可证](https://img.shields.io/badge/License-MIT-green) ![版本](https://img.shields.io/badge/Version-1.2.6-blue)

## ✨ 功能

### 📝 **任务管理**

* **分类任务**：预设5类任务（工作、个人、健康、学习、兴趣）
* **实时任务统计**，支持追踪完成任务
* **流畅的动画**：轻松愉快的使用体验
* **增强的本地存储**：所有数据保存在 Obsidian 笔记库中，稳定可靠
* **完整时间戳**：记录任务创建与完成时间

### ⏰ **智能提醒**

* **直观的日期/时间选择器**：独立输入，提升用户体验
* **浏览器通知**：支持自定义图标
* **灵活的过期处理方式**：
  * 可手动保留过期提醒
  * 也可自动删除过期提醒
* **会话持续**：重启 Obsidian 后仍然保留原有提醒

### 📅 **可视化日历**

* **月视图**：导航直观
* **任务和提醒视觉标识**：
  * 绿色圆点：表示当天新增任务
  * 橙色圆点：表示当天有计划提醒
* **清晰图例**：快速识别
* **响应式设计**：适应侧边栏宽度
* **交互式日详情**：点击事件日期可查看具体内容

### 🔄 **习惯追踪**

* **可视化界面**：美观、交互友好
* **自定义习惯**：6种颜色可选
* **7日追踪视图**：一周习惯完成情况一目了然
* **连续记录系统**：

  * 显示当前连胜天数
  * 记录历史最佳连胜
  * 自动计算与更新
* **每日交互标记**：

  * 点击圆圈标记完成/未完成
  * 今日有特殊高亮
  * 清晰区分已完成与漏打卡
* **本地持久保存**：数据保存在 Vault 中
* **响应式设计**：适配不同屏幕与主题

### 🍅 **番茄钟**

* **专业效率计时器**：带圆形进度可视化
* **可配置时间周期**：

  * 工作时间（1-60分钟，默认25分钟）
  * 短休息（1-30分钟，默认5分钟）
  * 长休息（5-60分钟，默认15分钟）
* **智能会话管理**：

  * 自动切换工作与休息周期
  * 可设置长休息前的工作轮次（2-8次，默认4次）
  * 实时统计会话与周期
* **增强用户体验**：

  * 圆形动画计时器，视觉美观
  * 启动/暂停/重置/跳过控件，提供视觉反馈
  * 无声通知，尊重 Obsidian 通知系统
  * 可自动开始下一个阶段
* **快速设置**：在计时器视图中即时调整
* **主题适配**：计时器颜色与6种主题协调一致

### 🎨 **精美主题**

6种精心设计的配色方案任你选择：

* 🎨 **默认主题**：清新充满活力
* 🌊 **海洋**（蓝绿色）- 宁静水感
* 🌲 **森林**（绿色）- 自然清新
* 🌸 **落日**（粉橙色）- 温柔晚霞
* 💜 **紫罗兰** - 富有创意
* 🌙 **午夜**（深蓝色）- 深度专注模式

### 🌍 **多语言支持**

* **完整罗马尼亚语支持**：本地化体验
* **完整英语支持**：国际无障碍
* **智能问候语**：自动识别合适的称呼与占位符
* **即时切换语言**：设置中更改立即生效

### ⚙️ **可定制设置**

* **个性问候语**：输入你的名字，享受专属每日问候
* **主题选择**：挑选你喜欢的配色方案
* **语言偏好**：罗马尼亚语或英语任你选

## 🚀 安装方式

### 方法一：手动安装

1. **下载插件文件**：

   * `main.js`
   * `manifest.json`
   * `styles.css`

2. **创建插件文件夹**：

   ```
   YourVault/.obsidian/plugins/mindfuldo/
   ```

3. **复制文件**到上述文件夹

4. **在 Obsidian 中启用插件**：

   * 打开 设置 → 社区插件
   * 找到 “MindfulDo”，开启它（🟠提醒：插件默认语言为Romana，可切换为英语 Engleza）

### 方法二：通过 BRAT 安装（Beta）

1. 安装 BRAT 插件（如尚未安装）
2. 在 BRAT 设置中添加该仓库地址
3. 在社区插件中启用此插件

## 🎯 使用方法

### 入门

1. 点击侧边栏的对勾图标打开插件
2. 在 设置 → MindfulDo 设置 中配置偏好
3. 使用直观界面开始添加任务

### 添加任务

* 在输入框输入任务
* 回车或点击“添加”
* 任务会按当前筛选器自动分类
* 点击复选框标记为已完成

### 设置提醒

* 输入提醒描述
* 从日历中选择日期
* 用时间选择器设置时间
* 点击“添加提醒”

### 使用习惯追踪器

* 进入“🔄 Obiceiuri”标签页（英文为“🔄 Habits”）
* **新增习惯**：

  * 输入名称（如“喝水”、“阅读”、“锻炼”）
  * 选择颜色（6种可选）
  * 点击“添加”建立习惯
* **追踪每日进度**：

  * 查看最近7天的圆形标记
  * 点击圆圈标记完成（✓）或未完成
  * 今日圆圈有特别边框高亮
  * 完成天数以所选颜色显示
* **查看连续记录**：

  * 当前连胜显示连续完成天数
  * 最佳连胜显示历史最高
  * 自动更新记录

### 使用日历

* 通过标题箭头切换月份
* 任务日显示绿色圆点
* 提醒日显示橙色圆点
* 当前日期高亮显示
* **点击有事件的日期**查看下方详情

### 使用番茄钟

* 进入“🍅 Pomodoro”标签页
* **开始会话**：点击播放按钮开始工作时间
* **暂停/恢复**：点击暂停按钮暂停计时
* **重置**：重置当前阶段时间
* **跳过**：立即进入下一阶段
* **查看进度**：圆环随时间填充
* **查看统计**：显示已完成会话与当前周期
* **快速调整**：直接在视图中修改时间
* **通知提示**：会话结束时收到提示（需开启通知）

### 设置主题

* 通过插件设置选择主题
* 修改后立即在各界面生效
* 所有 UI 元素统一配色风格

## ⚙️ 配置选项

| 设置项         | 说明                |
| ----------- | ----------------- |
| **你的名字**    | 用于个性化每日问候         |
| **语言**      | 可选英语或罗马尼亚语        |
| **配色主题**    | 从6个精美主题中选择        |
| **过期提醒**    | 保留或自动删除           |
| **侧边栏位置**   | 左/右侧显示插件          |
| **可见项控制**   | 设置滚动前最多可见项数       |
| **工作时间**    | 番茄钟工作时长（1-60分钟）   |
| **短休息**     | 短休息时间（1-30分钟）     |
| **长休息**     | 长休息时间（5-60分钟）     |
| **长休前工作次数** | 长休息前需完成工作轮次（2-8次） |
| **自动开始休息**  | 工作完成后自动进入休息       |
| **自动开始工作**  | 休息后自动进入工作         |
